About

SudoSudo is a "local" IP and port scanning tool built with Python and an HTML5 interface, using WebView and a local socket server to connect the backend with the frontend.

It can scan authorized targets, identify responding hosts and services, collect network information, store scan results, and send the collected output to an AI analyst for interpretation.

The AI analyst can process both textual scan results and images, while distinguishing confirmed information from assumptions and avoiding unsupported conclusions.

Philosophy

The project is mainly focused on network diagnostics, information gathering, automation, and experimentation, with an emphasis on keeping the interface simple while providing useful technical analysis.

Built because Python GUIs are ugly.
